# 🛍️ MIST.UA — Лендінг товару для дропшипінгу (шаблон)

Готовий лендінг односторінкового магазину одягу (худі oversize) на
**React + Vite + TypeScript + Tailwind CSS v4**. Мобільний-first,
українською мовою, з усіма конверсійними секціями та заглушкою
інтеграції оплати (LiqPay / Fondy / WayForPay).

> Це шаблон для **тестового дропшипінг-магазину**: заміни тексти,
> фото, ціни та підключи платіжку — і лендінг готовий до запуску.

## 🚀 Швидкий старт

Потрібні **Node.js 18+** та npm.

```bash
# 1. Клонуй або скопіюй проєкт і встанови залежності
cd dropship-landing
npm install

# 2. Запуск у режимі розробки (http://localhost:5173)
npm run dev

# 3. Продакшн-збірка (папка dist/)
npm run build

# 4. Локальний перегляд збірки
npm run preview
```

### Як змінити товар / тексти

Усе редагується в **одному файлі** — `src/data/product.ts`:

| Що змінити        | Де                                                              |
| ----------------- | --------------------------------------------------------------- |
| Назва, ціна, опис | `PRODUCT`                                                       |
| Розміри, кольори  | `PRODUCT.sizes`, `PRODUCT.colors`                               |
| Фото товару       | поклади файли в `public/img/` та онови `PRODUCT.images`         |
| Переваги          | `BENEFITS`                                                      |
| Відгуки           | `REVIEWS`                                                       |
| Питання FAQ       | `FAQS`                                                          |
| Контакти, соцмережі | `Footer.tsx`                                                  |
| Фірмові кольори   | `src/index.css` → блок `@theme` (змінні `--color-*`)            |

> 📸 **Фото товару:** SVG-плейсхолдери згенеровані скриптом
> `python3 scripts/gen-placeholders.py`. Для продакшену заміни їх на
> реальні фото (рекомендовано: 1000×1250, WebP, 5–7 ракурсів).
> Розмір фото сильно впливає на конверсію дропшипінг-лендінгу.

## 💳 Підключення оплати (LiqPay / Fondy / WayForPay)

Файл `src/lib/payment.ts` містить **заглушку** `createPayment()`, яка
імітує створення платежу, плюс **готові приклади коду** для всіх трьох
провайдерів (Node.js) із коментарями.

### Загальна схема (для всіх провайдерів)

```
Форма (фронтенд)  →  Твій бекенд  →  Платіжний провайдер
                        │                    │
                        └── checkout-URL  ←──┘
                        │
                  redirect на сторінку оплати
                        │
        провайдер повертає покупця на сторінку успіху
```

1. **Зареєструйся** у провайдера та отримай ключі:
   - **LiqPay** — кабінет → «Налаштування» → Public key / Private key.
     Тестовий режим: `sandbox_*` ключі + `sandbox: 1`.
   - **Fondy** — кабінет → Merchant ID + Secret key. Тестовий режим:
     увімкни «Тестовий режим» у налаштуваннях.
   - **WayForPay** — кабінет → Merchant Account + Secret key.

2. **Створи бекенд-функцію** (найпростіше — Vercel Serverless
   Function, див. розділ «Деплой»), яка:
   - приймає дані замовлення;
   - створює платіж за прикладом з `src/lib/payment.ts`;
   - повертає `{ url: checkoutUrl }`.

3. **У фронтенді** заміни тіло `createPayment()` на виклик свого
   бекенду:

   ```ts
   const res = await fetch('/api/create-payment', {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify(order),
   })
   return await res.json()
   ```

4. **Секретні ключі зберігай ТІЛЬКИ у змінних оточення** на бекенді
   (наприклад, `LIQPAY_PRIVATE_KEY`), ніколи не в коді фронтенду.

5. **Callback-URL** — провайдер надсилає на нього статус оплати
   (`server_url` / `server_callback_url` / `serviceUrl`). Там
   підтверджуй замовлення та надсилай покупцю трек-номер.

6. У тестовому режимі використовуй тестові картки провайдера
   (наприклад, LiqPay: `4242 4242 4242 4242`, будь-який CVV і дата).

### Альтернатива без свого бекенду

Якщо не хочеш писати бекенд, можна використати готові сервіси-
конструктори (наприклад, **WayForPay** має простіший flow через
редирект, а **LiqPay** — платіжні сторінки). Або відправити замовлення
у **Telegram-бот** (безкоштовно) і приймати оплату при отриманні —
для старту дропшипінгу цього часто достатньо.

## ☁️ Деплой на Vercel

### Варіант A — через веб-інтерфейс (найшвидший)

1. Запуш проєкт у GitHub-репозиторій.
2. Зайди на [vercel.com](https://vercel.com) → **Add New → Project**.
3. Обери репозиторій. Vercel сам визначить Vite:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Натисни **Deploy** — через ~1 хвилину отримаєш посилання
   `https://твій-проєкт.vercel.app`.

### Варіант B — через CLI

```bash
npm i -g vercel
vercel        # перший запуск: вхід в акаунт + налаштування
vercel --prod # продакшн-деплой
```

### Деплой бекенду оплати на Vercel

Створи в корені проєкту папку `api/` з функцією
`api/create-payment.ts` — Vercel автоматично підхопить її як
Serverless Function:

```ts
// api/create-payment.ts — приклад для Fondy (Node.js)
import type { VercelRequest, VercelResponse } from '@vercel/node'

export default async function handler(req: VercelRequest, res: VercelResponse) {
  const order = req.body
  // TODO: створи платіж у Fondy (див. src/lib/payment.ts) і поверни URL
  res.json({ url: 'https://pay.fondy.eu/...' })
}
```

Секретні ключі додай у **Settings → Environment Variables** на Vercel
(наприклад, `FONDY_SECRET_KEY`), а в коді читай через
`process.env.FONDY_SECRET_KEY`.

## 🎨 Що всередині

| Секція      | Що робить                                                     |
| ----------- | ------------------------------------------------------------- |
| Header      | Фіксована «скляна» шапка з CTA-кнопкою                        |
| Hero        | Заголовок, ціна зі знижкою, 2 CTA, соціальні докази           |
| Benefits    | 4 картки переваг (матеріал, крій, доставка, повернення)       |
| Gallery     | Слайдер: свайпи пальцем, стрілки, точки, мініатюри, автоплей  |
| Reviews     | Відгуки з рейтингом ★ та бейджем «покупка підтверджена»       |
| FAQ         | Акордеон із плавним розкриттям                                |
| OrderForm   | Ім'я, телефон, розмір, колір, місто/відділення НП, оплата     |
| Footer      | Контакти, соцмережі, способи оплати, копірайт                 |

Технічні фішки: мобільний-first, анімації появи при скролі
(IntersectionObserver), валідація форми, маска-перевірка телефону,
семантична розмітка та `aria-` атрибути.
